From the command line

Everything here can also be done against the running container — useful when nobody can sign in. Ownership can only be transferred this way, on purpose: it is the one change no session should be able to make. 

docker compose exec app phs-server user list
docker compose exec -e PHS_NEW_PASSWORD=… app phs-server user create bob
docker compose exec app phs-server user grant-admin bob
docker compose exec app phs-server user set-owner bob
