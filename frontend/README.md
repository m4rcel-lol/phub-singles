# frontend

The Angular application for pornhub.singles: the landing page, the public bio page
(`/<handle>`), the legal pages and the admin panel.

```bash
npm install
npm start          # dev server on :4200, proxying /api to the Go backend on :8080
npm run build      # production build into dist/frontend/browser
```

See the [root README](../README.md) for the full build, run and deployment instructions.
